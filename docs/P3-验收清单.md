# P3 验收清单

## 必须验证

- 未登录访问 AI 接口返回 401。
- 非管理员访问 AI 接口返回 403。
- 未绑定项目的管理员访问对应项目返回 403。
- 缺少或错误 CSRF 返回 403。
- 提示注入、密钥请求、SQL 请求被拒绝。
- 时间范围超过 90 天被拒绝。
- DeepSeek 不可用时返回固定查询降级结果。
- 返回数字与固定查询结果一致。
- 审计日志不保存密码、密钥或完整连接串。
- 每日限额和每分钟限流生效。
- 平乡公开演示页不出现 RDS `test` 数据。
- 宁晋演示页不出现平乡企业名称或记录 ID。
- P1 Webhook、P2 登录、平乡正式页面和公开演示页面无回归。

## 上线后检查

```text
GET  /api/auth/session
GET  /api/gov/pingxiang/dashboard
POST /api/gov/pingxiang/assistant/query
GET  /gov/pingxiang
GET  /gov/pingxiang-demo
GET  /gov/ningjin-demo
```

AI 请求必须使用正式登录会话和 CSRF 令牌，不使用内部接口密钥模拟浏览器登录。
