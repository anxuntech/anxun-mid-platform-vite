# P2 越权测试报告

## 测试范围

本报告覆盖正式平乡入口、认证会话、项目范围、企业与记录定位、草料诊断接口、受控下载、公开演示入口和账号禁用后的会话失效。

正式入口为 `/gov/pingxiang`，公开演示入口为 `/gov/pingxiang-demo`。正式接口固定读取 P1 MySQL 数据底座，不允许回退到 JSONL 或演示数据。

## 本地自动化结果

| 场景 | 预期 | 结果 |
| --- | --- | --- |
| 未登录访问正式页面 | 跳转登录并保留原地址 | 通过 |
| 未登录访问平乡聚合、企业、记录和导出 API | 返回 401 | 通过 |
| 非可信来源登录或导出 | 返回 403 | 通过 |
| 伪造前端本地存储 | 不产生服务端身份 | 通过 |
| 无项目绑定访问平乡项目 | 返回 403 | 通过 |
| 修改企业编号或记录编号 | 只在已授权项目内查找，不存在返回 404 | 通过 |
| 项目查看者下载企业记录明细 | 默认返回 403 | 通过 |
| 项目查看者下载阶段报告及两类汇总 | 允许并记录下载日志 | 通过 |
| 匿名访问草料原始事件诊断接口 | 返回 401 | 通过 |
| 项目查看者访问草料诊断接口 | 返回 403 | 通过 |
| 公开演示入口 | 只使用前端演示数据，不调用真实 API | 通过 |
| 正式数据源配置错误 | 返回归集异常，不回填演示数字 | 通过 |
| 代理 IP 头由非本机来源伪造 | 忽略伪造头，使用直连地址 | 通过 |

## 线上验收记录

线上验收必须使用三个独立正式账号完成：

- 安巡管理员；
- 平乡县应急管理局项目查看账号；
- 平乡人保项目查看账号。

验收时不在本报告记录密码、会话 Cookie、Webhook 密钥或完整连接串。账号、机构、项目范围、下载结果和禁用测试结果以数据库审计记录为准。

## 结论规则

只有当线上三个账号登录、项目隔离、下载分权、下载审计、账号禁用旧会话失效及公开演示隔离全部通过后，本报告结论才可标记为“生产验收通过”。
